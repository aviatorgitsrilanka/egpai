# Aviator Predictor — арабская версия для презентации

Это локальная копия исходного лендинга для школьной презентации о кибербезопасности и интернет-мошенничестве.

## Что сохранено

- исходная структура, оформление и анимации;
- окно ввода кода и основной сценарий;
- демонстрация «сигналов», лента игроков и чат;
- адаптивный вид для телефона и компьютера.
- арабский интерфейс с направлением RTL;
- египетская валюта EGP и локализованные имена.

Код доступа для демонстрации: **1187**.

После расчёта нажмите **فتح تيليجرام — مهدي** или ссылку `@MEHDIAPK_BOT`: откроется официальный сайт Telegram. Промежуточных страниц регистрации и пополнения в комплекте нет.

## Что изменено ради безопасности

- крупные верхняя и нижняя плашки заменены небольшим арабским маркером `محاكاة توعوية`;
- кнопки не ведут к реальному боту: они открывают официальный сайт Telegram;
- прямые ссылки `t.me` и сайты казино остаются заблокированными;
- отправка данных во внешние сервисы заблокирована;
- внешнее видео заменено локальной заглушкой;
- CSS, JavaScript, шрифты и изображения хранятся внутри папки;
- политика безопасности браузера запрещает сетевые запросы страницы;
- поисковым системам запрещено индексировать эту копию.

На странице нет добавленных трекеров, аналитики, платёжных форм или реальной системы прогнозирования.

## Запуск на компьютере

Самый простой вариант — открыть `index.html` двойным щелчком. Если браузер ограничит локальные скрипты, откройте терминал в этой папке и запустите:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация на своём хостинге

Загрузите **всё содержимое этой папки** в корневую папку сайта, обычно она называется `public_html`, `www` или `htdocs`. Главным файлом должен остаться `index.html`.

Для Vercel:

1. Установите Vercel CLI: `npm install -g vercel`.
2. Откройте терминал в этой папке.
3. Выполните `vercel --prod` и следуйте подсказкам.
4. В настройках проекта подключите свой домен.

Для Netlify можно перетащить всю папку в Netlify Drop, затем подключить домен в настройках сайта.
